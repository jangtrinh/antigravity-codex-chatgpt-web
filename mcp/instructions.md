# Codex ChatGPT Web MCP Tool Guide

Sử dụng tool `ask_chatgpt_web` khi người dùng muốn:
- Hỏi ý kiến, suy luận hoặc viết code bằng tài khoản ChatGPT Web Pro / Plus (sử dụng hạn ngạch ChatGPT web cá nhân thay vì API token tính phí).
- Chọn model theo yêu cầu:
  - `chatgpt-web/pro`: Dành cho các tác vụ suy luận cực kỳ phức tạp (yêu cầu gói ChatGPT Pro).
  - `chatgpt-web/high`: Mức suy luận cao (High reasoning).
  - `chatgpt-web/medium`: Mức suy luận trung bình, cân bằng tốc độ và chất lượng (mặc định).
  - `chatgpt-web/light`: Tốc độ phản hồi tức thì (Instant).

Sử dụng tool `ask_codex_native` khi:
- Cần chạy qua mô hình gốc Codex GPT-6-Astra.
